A paper-trading bot for the pump.fun replay sprint. Each slot it reads the
batch of chain events, looks for fresh curves showing early buy momentum, opens
small starter positions sized under the per-mint reserve cap, and takes profit
or cuts losers on a bps threshold — spreading risk across many coins to clear
the 20-coin round-trip guardrail without ever holding more than five positions.

## Run it

```sh
node main.ts
```
